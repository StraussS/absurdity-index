# 今日荒谬指数 - 简版 PRD

## 1. 项目概述

### 项目名
今日荒谬指数

### 一句话定位
今天的世界，离谱到几分？

### 核心价值
把每天最像段子、最反常识、最有赛博荒诞感的新闻与热点事件，整理成一个可视化、可分享、可连续追踪的数据产品。

---

## 2. 目标用户

### 核心用户
- 关注互联网热点的人
- 喜欢产品感 / 数据可视化的极客用户
- 喜欢讽刺、评论、社会观察内容的人
- 独立开发者、媒体从业者、AI 圈用户

### 使用场景
- 每天快速刷一眼“今天有多离谱”
- 看到一条新闻时，想知道它在全网离谱程度里排第几
- 截图分享当天最荒谬事件

---

## 3. 产品目标

### V1 目标
- 做出一个能上线传播的首页
- 明确“荒谬指数”表达方式
- 用少量内容跑通内容生产流程
- 建立稳定的数据结构，为后续自动化抓取做准备

### 非目标
- 暂不做复杂用户系统
- 暂不做大规模爬虫平台
- 暂不做评论社区

---

## 4. V1 功能范围

### 4.1 首页
- 今日荒谬指数总分
- 风险等级
- 今日一句总结
- 今日最荒谬 TOP 5
- 维度评分可视化
- 7 日趋势图

### 4.2 单条事件字段
- 标题
- 来源
- 时间
- 分类
- 荒谬分
- 短吐槽
- 原因说明
- 原始链接
- 维度评分

### 4.3 数据生产方式
V1 允许半人工：
1. 手动录入新闻标题、来源、链接
2. AI 输出评分、吐槽、原因说明
3. 汇总为今日 JSON

---

## 5. 页面结构

### 首页模块
1. Hero：标题 + 今日总指数 + 状态建议
2. 总览卡片：总分 / 最荒谬领域 / 关键词
3. TOP 5 列表：卡片式新闻
4. 维度图表：条形图或雷达图
5. 趋势区：近 7 天 / 30 天
6. 页脚：关于项目 / 提交入口 / 指数方法

---

## 6. 指数规则

### 评分维度
- 反常识
- 黑色幽默
- 系统性离谱
- 传播戏剧性
- 赛博浓度

### 指数等级
- 0-39：轻微抽象
- 40-69：中度荒谬
- 70-100：高危荒谬

---

## 7. 内容语气

### 原则
- 半认真，半讽刺
- 不做纯段子站
- 不脱离事实胡编
- 吐槽短而准
- 看起来像一个“很清醒的数据编辑部”

### 不要
- 不要低级烂梗
- 不要情绪化谩骂
- 不要像营销号标题党

---

## 8. 推荐技术方案

### 前端
- Next.js
- Tailwind CSS
- shadcn/ui
- Recharts / ECharts

### 数据
- V1: 本地 JSON
- V2: SQLite / Postgres

### AI 工作流
- 输入：新闻标题、正文、来源
- 输出：结构化 JSON（分数、维度、吐槽、原因）
